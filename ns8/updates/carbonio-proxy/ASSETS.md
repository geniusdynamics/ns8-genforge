# Carbonio assets

Logo: official Carbonio branding from https://docs.zextras.com/carbonio-ce/html/_static/carbonio-black.svg (rasterized to PNG).

Screenshots: genuine upstream Carbonio webmail and conversation views from https://docs.zextras.com/user-guides/carbonio/en/html/browsing_emails/toc.html (`read-email.png`, `conversation-view.png`). These show the Carbonio client served through the edge proxy, not a separate proxy administration interface.
