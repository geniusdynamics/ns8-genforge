Missing an app, or found a bug?

Every module has its own repository on GitHub. Report a bug there, ask for a new app, or send a pull request.

To install: open Settings › Software repositories on your cluster, add the URL above, then use the Software Center. Turn on Testing only if you want pre-releases.
